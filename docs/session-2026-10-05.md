## What broke and what it taught
- `next build` in the worktree was refused (it would overwrite `.next` under a running server). Build in
  a scratch copy instead: `rsync` the tree (no node_modules/.next/.git), `cp -cR` node_modules
  (Turbopack rejects a symlinked node_modules), `next start` on your own port.
- The :3007 dev server didn't pick up `app/globals.css` edits; don't trust it for token changes.
- A block parent with `justify-items: center` shrinks an absolutely-filled child to 0 width (cover bug).
- Clip sweep counts transparent text as visible: hide text with `visibility: hidden`, not colour.
- Any focusable control inside a `role="img"`/aria-hidden picture fails axe: split the picture and put
  the control between (ShowAll, Federated Fig 3, CHIP Fig 1, Theming repo).
- Figma clone exports lose the parent's fill and variable modes: copy both before exporting.
- audit:fonts fails on the words "Geist Mono" in a comment.
