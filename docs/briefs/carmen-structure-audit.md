Let's chat instead", book a call) → Next Case card → "Made with ..." transparency footer. A reading-progress indicator runs in the header.

## 2. Why it works

- Every section is problem → solution, stated in one breath before any image.
- Text sits beside its visual; sections are one idea each (the Justine rules, applied).
- The system work is SHOWN as artifacts (swatches, type ramp, tokens file, Storybook, before/after), not described.
- The differentiator gets its own named band; it is the hire-me argument, not a footnote.
- Outcomes are honest and qualitative, explicitly "no invented numbers", which reads senior, not evasive.
- The page never dead-ends: journey → chat CTA → next case.
- Personality lives in the voice and one CTA moment, not in the layout.
