## Decisions, and why
- **The TodoNote guard keys on `VERCEL_ENV` on Vercel, `NODE_ENV` off it.**
  `next build` sets `NODE_ENV=production` on previews too, so `NODE_ENV`
  alone would hide the notes where Elleta reviews them.
- **CaseEndReveal was replaced, not kept beside the new block** (Elleta's
  pick). Two next-case links on one page would break the one-implementation
  rule. "Thanks for reading", Share and the end back link went with it.
- **case-end fires on the ending block, not on the last content section**
  (Elleta). One rule for every case; the last-section version fired at
  load on Search, which is a single section.
- **CaseEnd is not a ruled Section.** On the mock cases `audit:visual`
  requires a ruled section to open on an eyebrow and an h2, and the block
  holds neither by design.
- **Drift phone details are crops via viewBox plus a clip-path**, not new
  assets. `audit:contain` accepts clip-path and hidden SVG overflow as
  deliberate clipping. Crop widths are set so labels compute 13px or more
  down to a 360 phone (grave 240 units, file 104 units; the file draws its
  labels at 13 units scaled by 0.4005).
- **No visible TODOs on the live site** (Elleta). Open copy questions are
  tracked in the private report, not on the page.

## What broke, and what it taught
- A first Drift crop put the whole-file labels at 12.3px. Measuring the text
  box height (16px) hid it; compute font size from the viewBox scale instead.
- `gh pr merge --auto` is unavailable: auto-merge is off for the repo.
  Branch protection also requires branches up to date with main, so each PR
  needs `gh pr update-branch` after the one before it merges.
- The gate workflow run reads "failure" whenever the optional npm-audit job
  fails; read the `gate` check itself.
- `.text-action` is a flex link, so a bare space before an inline arrow
  drops. Keep label and arrow in one inline span.
- A second Claude session committed in this working tree mid-task (identical
  diff, so harmless). Two sessions in one checkout can collide.
