## Decisions and why
- **Portrait 540px, not the prototype's 564.** The cut-out is 1080px wide; 564 is over half its
  natural width, which audit:sharp fails (no upscaling). A re-cut from the 2167px original
  goes with Elleta's open photo decision.
- **The faint code is a picture** (`public/images/home/hero-code.webp`), not text: at its
  intended faintness it fails contrast, and section 9 says rule-breaking decoration ships as a
  picture. It sits in one masked group with the portrait so it never reads over her.
- **Hero frame exceptions are named and printed:** the Home h1 (story line, 77 characters,
  visually hidden) and the proof row's dropped bottom pad. Both carry dated reasons in
  `data-frame-exempt` and audit:frame lists them every run.
- **Home JS budget 240 KB gz** (CLAUDE.md section 9, not gated): the React and Next framework
  chunks alone are about 158 KB, so the old 146 KB was below the floor.
- **The favicon is the site's brand mark, not BELLA's** (Elleta, 4 Oct): it left
  `scripts/sync-bella.mjs` and the manifest; BELLA keeps its own mark.
- **The 16px favicon frame has its own cut** with 2px bars (not 2.5): whole pixels only.
- **Kept ours over the prototype on three:** the site nav (not the black bar), the code line
  visible in every state and on phones, the peach chip (no pink in the palette).

## What broke and what it taught
- **The global `img { max-width: 100% }` squashed the portrait** to 100% width for two steps
  (18c, 18d) before measurement caught it. Any image meant to overflow its box needs
  `max-width: none`.
- **A stale dev server misled two reviews** (`:3005`, running since 3 Oct): flat plates at
  2000px, misaligned words, 404s. Restart the dev server after any build before judging it.
- **`audit:sync` failed only against `~/DEV/bella`'s local edits**, not real drift: always run
  it with `BELLA_SRC` pointing at a clean export of BELLA origin/main.
- **A mask clips to its element's box:** the portrait (120%) and code overflow the layer, so the
  fade lives on a wider wrapper (1.6x the stage, 1.2x on phones, which audit:frame caught
  overflowing at 390).
- **Negative bottom margins collapse through wrappers** and overshoot; the phone photo uses a
  relative offset instead.

## Decisions and why
- **Dark primary hover goes to white, not BELLA's #cdcdcd:** BELLA's dark stop darkens the plate,
  which reads as dimming; #f2f2f2 is a 5-step lift that doesn't read. Elleta confirmed white.
- **btn-key keeps raw `11px 18px` padding and the 1.5px secondary border**, commented: no exact
  token, and a swap would shift every button.
- **Hover guard exceptions:** the WorkLibrary tooltip stays unguarded (tap is how touch reaches
  it); vendored BELLA modules aren't edited (Card and Trace need the guard upstream).
- **The Home LCP problem was bandwidth, not the reveal:** the portrait paints at 108ms
  unthrottled. Under real throttling it's now 1.4s (was 2.8 to 3.3); Lighthouse's default
  simulated mobile LCP is 4.4s (was 6.0) because its model puts the JS on the image's path.
- **/quick LCP left alone:** its LCP is the section field, which RouteField sets after hydration.
  Fixing it means server-rendering the fields on every route, a visible timing change, so it
  waits for Elleta.
- **The 800w cut is sharp at 2x:** the portrait lays out at most 396px below 901px; 3x phones
  still take the 1080. Pixel diff against the 1080 at 390 2x: mean 0.9/255.

## What broke and what it taught
- **A script that rewrites CSS rules mangled a multi-line selector with a one-line body**
  (`.dfc-mark ...::before`), and the build failed with "Unclosed block". After any scripted CSS
  rewrite, parse every file with postcss and diff the (selector, property, value) triples
  against HEAD before building.
- **`node -e '...' -- a b` puts `a` in argv[1], not argv[2]:** an equivalence check reported
  "equivalent" while skipping globals.css. Print the file count in any check like that.
- **Screenshots taken right after Tab catch the label roll mid-transition.** Wait for the
  longest transition plus 100ms, and check `document.getAnimations()` before calling it a bug.
- **Safari's Tab skips links;** test link focus in WebKit with Option+Tab.
- **Lighthouse's simulated LCP and a real throttled load disagree on Home;** report both.
